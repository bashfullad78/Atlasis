# v0.2 Implementation Log

> Version log, not a research analysis — what was built, which files changed,
> which bugs bit, and what still constrains the system. Findings and corrected
> numbers live in `docs/analyses/analysis-v0.2.md`.
>
> Period: 2026-09-11 → 2026-09-13. Test suite: 33/33 (all offline).

## Shipped

1. **Corrected population layer** (started 09-11, completed this period):
   density→count conversion (`count = density × geodesic cell area`),
   country-agnostic WorldPop source selection, Parquet per-city caches,
   legacy-CSV rejection. All four v0.1 cities rerun; every v0.1 figure
   reconciles mechanically via per-city latitude factor k (see analysis doc).
2. **Self-healing `meta.json`**: any resolved city fact (UTM zone, ISO3,
   population provenance) is written back once, so later runs are offline.
   All five cached cities backfilled.
3. **One-command city bootstrap**: `python -m backend.main --city X --place
   "City, Country"` fetches missing artifacts (boundary → roads → hospitals →
   forbidden → population), is resumable, and runs offline when everything is
   cached. `--probe` previews, `--no-download` forbids fetching.
4. **Slim road-graph format**: two zstd Parquet tables per city instead of
   OSMnx GraphML — 116 MB → 6.3 MB across five cities (~95%), topology and
   lengths verified identical; pipeline outputs byte-equivalent. GraphML
   loader kept as fallback; old files deleted via the cleanup tool.
5. **Cleanup tool** (`backend.data.cleanup`): dry-run plan + `--apply` +
   `--only KIND` for re-derivable artifacts (processed outputs, orphaned
   `.part` files, superseded GraphML, spent national rasters).
6. **Kampala validated end-to-end** (first non-India city): bootstrap
   completed under flaky Overpass across three resumable runs; 5-min results:
   98.7% → 99.8% coverage, +19,395 people, population total within ~1% of the
   official figure.
7. **Heidelberg onboarding exercise** (third country): boundary/meta/roads/
   hospitals fetched; blocked only on the forbidden step by Overpass
   instability (see constraints).

## Noteworthy bugs found & fixed

| Bug | Fix |
|---|---|
| Mysuru v0.1 "94.7% @ 5-min" irreproducible from committed data | Root-caused to the polygon-restricted facility class (19 facilities): reproduces at 93.5% / +24,140 = 28,771 ÷ 1.192. The v0.1 doc's dataset block ("~85 hospitals") mislabeled its own headline experiment; both docs now state the facility class explicitly. |
| Meta helpers placed above `CityConfig` → `NameError` at import | Eager annotations; moved below the dataclass. |
| `test_persist_meta_creates_dir_and_file` forgot to monkeypatch `DATA_DIR` | Wrote `data/raw/brandnew/` into the real repo during a test run; test fixed, stray dir removed. Also the reason the cleanup/sitrep audit exists. |
| Function-level imports in `prepare.py` untestable (unpatchable) | Moved to module-level imports. |
| Parquet write crashed: `Expected bytes, got 'list'` on `highway` | OSM list-valued tags (e.g. `highway=['residential','footway']`) break Arrow inference on mixed object columns → nullable `list<string>` columns with scalar wrap/unwrap. |
| Roundtrip test: `osmid == None` on some edges | Merged ways carry list osmids (`[140226540, 1542856908]`); an `int()` cast silently dropped them → nullable `list<int64>` column. |
| Roundtrip test: `[False, True] == True` on `reversed` | GraphML can carry list-valued `oneway`/`reversed`; a `bool()` cast corrupted them → `list<bool>` columns. |
| `_unwrap` crashed on Parquet list columns | Values arrive as numpy object arrays, not native lists; ndarray branch added. |
| Slim-graph tests hard-linked repo `roads.graphml` | Broken once the GraphMLs were deleted; fixture now builds a synthetic graph through genuine `ox.save_graphml`. |
| Probe crashed on unresolvable country while offline | Raster size estimate made best-effort; probe always completes. |

## Constraints (current)

- **Overpass public instance dominates first-fetch UX.** Repeated TCP connect
  timeouts to `overpass-api.de` (server-side load-shedding; Nominatim and
  WorldPop were fast all day). The kumi.systems mirror worked when the primary
  didn't — but mirror fallback is not yet in code (used manually via
  `ox.settings.overpass_url`).
- **Forbidden-zones fetch is 5 sequential Overpass queries** with a 180 s hang
  per failed attempt; under instability this does not fit a 10-minute working
  window (three windows spent on Heidelberg's forbidden step). Combined query
  + fast-fail + mirror chain is the designed fix, deferred deliberately.
- **Data gaps from those timeouts**: Kampala's forbidden layer is missing the
  cemetery tag group; Heidelberg has no forbidden layer yet.
- **First-fetch only**: once cached, runs are fully offline and take ~1–2 min;
  warm-cache behavior is verified by tests and was exercised during a full DNS
  outage.
- **Everything since the v0.1 commit is uncommitted** (v0.2 layer, meta
  persistence, bootstrap, slim graphs, cleanup, docs, Kampala + partial
  Heidelberg data).
- v0.3 scope untouched: joint MCLP selection, 2SFCA accessibility index,
  uncertainty reporting, Streamlit demo.
